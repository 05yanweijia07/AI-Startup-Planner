# State Management Scenarios

1. **Minimal project creation:** unknown budget and customer stay null/empty; IDs match; no gate is falsely passed.
2. **Project recovery:** summary reflects persisted stage, decisions, evidence, blockers, and next actions; missing files are disclosed.
3. **Decision supersession:** prior choice remains traceable as superseded; new choice is linked; dependent deliverables are reviewed or marked stale.
4. **Evidence update:** source scope/date/limitations are recorded; affected claims and analyses are identified.
5. **Cross-project isolation:** updates to one project do not change another project's files or shared Skill source.
6. **Persistence unavailable:** provide a proposed state patch and do not claim it was saved.

Pass when records remain valid, provenance is retained, and downstream effects are visible.
